## 사이트 주소
http://mbti.soyyoda.com

## 프로젝트 소개
- 16가지 MBTI 유형에 더해 12가지 subtype까지 초개인화된 성격 유형을 제시하는 것을 목표했습니다.
- MBTI와 subtype을 종합해 LLM API가 초개인화된 성격 결과를 알려줍니다.
- 소요 시간은 56문항 대략 5분 이내로 간단한 테스트입니다.

## Subtype이란?
> Introvert(내향성) / 
> Extrovert(외향성) / 
> Ambivert(양향성) / 
> Omnivert(내향-외향 양극단을 오가는 유형) <br/>
> 위의 4가지 대분류를 기준으로 같은 mbti라고 같은 성격이 아니듯 I같은 E, I↔E를 전략적으로 전환하는 사람 등 다양한 유형을 구분하기 위해 사용
>
> Ambivert는 중간 지점에서 균형을 이루는 편이고 Omnivert는 I↔E를 전환하는 차이를 가진다.
